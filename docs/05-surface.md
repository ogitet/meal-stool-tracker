## 1. コンセプト：日めくり × 判子

**日々を、押していく。**

日めくりカレンダーの紙片に、食べたものの印（判子）を押していく帳面として描く。

| 要素 | 表現 | 由来 |
|---|---|---|
| 地 | 淡い空色の単色 | 目に優しい舞台。紙と印を引き立てる |
| 1日 | 白い紙片（角丸の札） | 日めくりの1枚 |
| 日付 | 落ち着いたゴシック体の数字 | 日めくりカレンダーの数字。主張しすぎない |
| 食べたもの | 1文字の印。グループごとのインク色 | 判子。少しずつ傾けて、手で押した表情を出す |
| 記録の操作 | チップを押すと、その場でインク色に変わる | 「選ぶ」ではなく「押す」 |

### 方針

| 方針 | 内容 |
|---|---|
| 大胆に、ただし1か所で | 強い表現は「太い数字・色の印」に集める。地は淡く保つ。それ以外（文字、余白、線）は静かにする |
| 評価しない | 色や形で、食事や便に良し悪しの印象を与えない。赤は警告ではなく、印のインク色の1つとして扱う |
| 色に頼りきらない | カテゴリは文字、便は形、選択状態はチェックと太字でも区別する |
| 褒めない | 保存時の祝う演出、継続を褒める演出は入れない。動きは「押した」「移った」を伝えるためだけに使う |

配色は、明るい配色と暗い配色の2種類とする。端末の設定（`prefers-color-scheme`）に従って切り替える。アプリ内の切り替えの操作は、今は置かない（Q30）。

| 紙 | `#FFFFFF` | `#20263F` | 今日の紙片、入力シート |
| 紙（淡） | `#F3F6FD` | `#181D32` | 過去の紙片、未選択のチップ |

| 削除の上の文字 | `#FFFFFF` | `#2A0D08` | 「削除する」の文字 |

### 暗い配色の考え方

- 明るい配色と同じく、地・紙（淡）・紙の順に明るくする。地は夜空の濃紺、紙片はそれより少し明るい紺にする。
- 墨は淡い色に入れ替わる。墨で塗る部品（選択中のセグメント、トースト、便の形状チップ）は、淡い塗りに暗い文字になる。
- 藍は明るくし、上の文字を暗くする。削除も同じ。
- 印のインク色は変えない。暗い地の上でも同じ色で見分けられるようにするため。「その他」だけは墨なので、淡い塗りに暗い文字へ入れ替える。
- 便マークの茶色は、暗い紙の上で見えるよう全体に明るくする。濃淡の順（硬い＝濃 → 下痢＝淡）は変えない。
- 影は黒に、確認シートの背後の幕も黒にする。

### 印のインク色（グループ）

| グループ | 背景 | 文字 | コントラスト比 |
|---|---|---|---|
| 主食 | `#F2C14E`（山吹） | `#3A2A00` | 8.28 |
| 肉・魚・卵 | `#C4472F`（朱） | `#FFFFFF` | 4.90 |
| 野菜・果物 | `#2D7F63`（緑） | `#FFFFFF` | 4.85 |
| その他 | `#2E3354`（墨）。暗い配色では `#DFE4F5` | `#FFFFFF`。暗い配色では `#1A1F36` | 12.23。暗い配色では 12.80 |
| お菓子 | `#F4A8C4`（桃） | `#4A0A2A` | 8.22 |

- 「その他」は揚げ物、辛いもの、お酒など、便との関係で特に見たいものの集まりであるため、最も濃い墨にする（Q32）。
- 追加したカテゴリは所属グループの色を使う。利用者が色を選ぶ操作は設けない。

## 3. 便マーク

単色（墨）の SVG とし、輪郭の形で4種を区別する。色は形状によって変えない（Q33）。

| 形状 | 形 | 図の説明 |
|---|---|---|
| 硬い | 小さな粒が3つ | 塗りの円3つを三角形に配置 |
| 普通 | 楕円 | 横長の塗りの楕円 |
| 柔らかい | 雲形 | 平らな底に、丸いふくらみが3つ並ぶ塗りの形 |
| 下痢 | しずく | 塗りのしずく形 |

- 排泄物を写実的に描かない。良し悪しを示す表情や記号を付けない。
- 月表示の前後の月の日では、薄く（55%）描く。
- 量と排便感はマークで表さず、日別詳細の文字でのみ示す。
- 将来ブリストルスケールに拡張するときは、マークを見直す。

## 4. タイポグラフィ

Web フォントを2書体使う（Google Fonts）。初回の取得後は Service Worker が端末に保持する。

| 役割 | 書体 | 使う場所 |
|---|---|---|
| 数字 | DM Sans 600 | 日付、期間、時刻。和文のゴシックとなじむ、静かな数字 |
| 和文 | Zen Kaku Gothic Antique 500／900 | それ以外のすべて。印の1文字は 900 |

読み込めない場合は、数字・和文ともヒラギノ角ゴにフォールバックする。

| 用途 | サイズ | 太さ |
|---|---|---|
| 週の日付 | 24px（今日は丸の中に 20px） | 600 |
| 期間の見出し（11/9–15） | 21px | 600 |
| ヘッダーの日付の数字 | 22px | 600 |
| 月表示の日付 | 15px | 600 |
| 時刻（日別詳細） | 17px | 600 |
| ボタン（保存、食事、便） | 17px | 900 |
| 本文、チップ、リスト | 15px | 500（選択中のチップは 900） |
| 印の1文字 | 14px | 900 |
| 見出しラベル（主食、形状など） | 11px、字間 .08em | 900 |

- ヘッダーの日付は「**11**月**10**日 ㊋」のように、数字を大きく、曜日を丸囲みで組む。
- 月の見出しは「**2026**年**11**月」の単位（年・月）を小さくする。

## 5. 形と余白

| 要素 | 値 |
|---|---|
| 入力シートの上の角丸 | 22px |
| 紙片（週の1日） | 角丸 14px、紙片の間隔 4px |
| 月のマス | 角丸 10px、間隔 3px |

| チップ | 角丸 10px、高さ 40px |
| ボタン | 角丸 12px（カレンダーの記録ボタンは 14px、高さ 48px） |

内側の画面（日別詳細、記録、カテゴリ）は、空色のヘッダーの下に白いシートを重ねた構成とする。線で区切り、カードは重ねない。

## 6. 部品の状態

| 部品 | 状態 | 見た目 |
|---|---|---|
| チップ | 未選択 | 紙（淡）、墨の文字 |
| | 選択 | グループのインク色で塗る。太字、左にチェック |
| | 選べない（外した「使わない」カテゴリ） | 塗らず細い枠のみ。補助文字色に打ち消し線。押せない |
| 便の形状チップ | 選択 | 墨で塗り、マークと文字を白にする |
| セグメント | 選択中 | 墨で塗り、白文字 |
| 保存ボタン | 有効／無効 | 藍に白文字／罫線色に補助文字 |
| 週の紙片 | 過去 | 紙（淡） |
| | 今日 | 紙（白）＋影。日付を藍の丸で囲み、曜日も藍（濃）にする |
| | 未来 | 塗らず、墨の薄い輪郭のみ。文字は墨の 50% |
| 月のマス | 今日 | 紙（白）＋影。日付を藍の丸で囲む |
| | 前後の月 | 白の 32% で塗り、文字は補助文字色 |
| 押下中 | 共通 | わずかに縮める（.96〜.985） |

### 動き

| 場面 | 動き | 時間 |
|---|---|---|
| 記録シートを開く／閉じる | 下からせり上がる／下へ降りる。奥の画面はわずかに退く | 340ms |
| 階層を進む／戻る | 右から入る／右へ出る | 340ms |
| カレンダーを左右に払う | 指に少しついてきて（移動量の35%）、60px 以上払うと週・月を送る。新しい期間は払った向きから入る。矢印と「今日」でも同じ向きに動く | 320ms |
| チップを押す | 少し縮んで傾き、戻る（判子を押す感触） | 280ms |
| カレンダーの印 | 大きめの状態から、順に押されるように現れる | 260ms、16ms ずつ遅延 |
| トースト | 下から浮かび上がる | 300ms |

- 画面遷移は View Transitions API で行う。対応していないブラウザでは、動きなしで切り替わる。
- 端末のスワイプ操作で戻った場合は、OS 側の動きと重ならないよう、アプリ側の動きを付けない。
- 端末の「視差効果を減らす」設定が有効なときは、すべての動きを止める。

## 7. 文言

## 8. アプリの外観

ホーム画面に常に表示されるため、記録の内容を連想させない外観にする（Q31）。

| 項目 | 内容 |
|---|---|
| アプリ名 | ひびログ |
| アイコン | 淡い空色の地の中央に、にっこり顔の日めくり1枚（ピンクの帯、白い頬紅、2つの目と口）と、右下に重なる小さな黄色の判子。食事や便のモチーフは使わない。[scripts/gen-icons.mjs](../scripts/gen-icons.mjs) で生成する。暗い配色でも同じ絵柄を使う（地を自前で塗っているため、暗いホーム画面やログイン画面の上でも見える） |
| ブラウザーの枠の色 | `theme-color` を配色ごとに指定する（明るい配色 `#CFDDF6`、暗い配色 `#0F1322`）。マニフェストの `theme_color` と `background_color` は値を1つしか持てないため、明るい配色のままにする。Android では、暗い設定でも起動画面だけ空色になる |
| ステータスバー | 半透明（`black-translucent`）。ページをステータスバーの下まで延ばし、空色の地を上端までつなげる。iOS 26.1 以降はこの指定で上端に端末側のぼかしがかかり、ページから消せない（2026-11-11 実機で確認。指定を外しても消えなかった）。そこで画面の上端を「安全領域の高さ＋12px」空け、ぼけるのが無地の余白だけになるようにする |

## 9. 判断事項

| # | 問い | 決定 | 理由 |
|---|---|---|---|
| Q30 | ダークテーマを用意するか（2026-11-16 変更） | 用意する。端末の設定に従って切り替える。初版の「用意しない」を変更。アプリ内の切り替えは今は置かず、必要になったら足す（`:root[data-theme]` で配色を固定できる） | 端末を暗い設定で使っているときに、このアプリだけ明るい画面にならないようにする。端末の設定に従うだけなら、操作も設定の保存もいらない。配色の検証が2通りになる分は、単体テストで計算して確かめる |
| Q31 | アプリ名とアイコン | 「ひびログ」、顔つきの日めくりのアイコン（Q42で変更） | ホーム画面で他人に見られても、記録の内容がわからない |
| Q32 | グループの配色 | 2章の5色。「その他」は墨 | 揚げ物の判別を G2 の基準に合わせて強める |
| Q33 | 便マークの表現 | 3章の4種。単色で、輪郭の形で区別する | 評価の印象や不快感を避け、小さくても区別しやすい |
| Q39 | 見た目の方向（2026-11-10 追加） | 「日めくり × 判子」。空色の地（Q41で変更）、数字（Q43でゴシックに変更）、色インクの印、画面遷移の動き | 初版は無難で印象に残らなかった。記録するたびに触りたくなる質感を、継続（G1）の後押しにする |
| Q40 | Web フォントを使うか（2026-11-10 変更） | 使う（2書体）。初版の「読み込まない」を変更 | 数字と印の表情がコンセプトの中心であるため。初回のみ読み込みが増え、以後は端末に保持する |
| Q41 | 地の色（2026-11-11 追加） | コバルト `#2A3FD4` → 淡い空色 `#CFDDF6`。ヘッダーの文字は白 → 墨。印の色も彩度を少し落とす | 実機で見たところ、コバルトが目に強かった。優しい色合いにしつつ、日めくり×判子の構図は保つ |
| Q42 | アイコンの絵柄（2026-11-11 追加） | 横線3本 → にっこり顔の日めくり＋小さな判子 | 実機で見たところ、無機質だった。可愛げを出しても、食事や便は連想させない |

初版からの主な変更は、配色（クリーム＋青緑 → 淡い空色＋白＋藍）、書体（システム書体 → Web フォント）、動き（最小限 → 遷移と押印）、「赤は削除のみ」の原則（→ 朱は印のインク色としても使う）の4点である。

## 10. 第2版の見た目（2026-11-26）

Strategy 第2版で、方針「評価しない」「褒めない」を「責めない、ただし励ます」（Strategy 原則5）に改めた。コンセプト「日めくり × 判子」と、配色・書体・形は初版第2版を引き継ぐ。

### 方針の変更

| 初版 | 第2版 |
|---|---|
| 評価しない（色や形で良し悪しを示さない） | 食べた日・食べなかった日・運動した日を、色ではっきり分ける。ただし食べた日に警告の色（赤）や否定の記号（×）を使わない |
| 褒めない（継続を褒める演出を入れない） | 連続日数とベストを数字で示す。祝う演出（紙吹雪など）は入れない |

### 色

| 対象 | 明るい配色 | 暗い配色 | 備考 |
|---|---|---|---|
| 食べなかった日のマス | `#D3EFDF`（淡い緑） | `#19382E` | トークン `--clean`。墨の文字とのコントラスト比は 4.5 以上（`palette.test.ts` で確かめる） |
| パンの印 | 山吹（主食の色） | 同じ | 角の印 |
| お菓子の印 | 桃（お菓子の色） | 同じ | 角の印 |
| 運動の印 | 緑（野菜・果物の色） | 同じ | 丸の印。食べたものの角の印と形でも区別する |

- 食べなかった日の色は、当初アクセントの藍を淡くした色で試したが、明るい配色では空色の地に溶け、食べた日（白いマス）のほうが目立ってしまった。緑系にして、食べなかった日のほうが目に入るようにした（試作で確認）。
- 追加した項目の色：減らしたいものは並び順に 山吹 → 桃 → 朱 → 墨、続けたいことはすべて緑とする。利用者が色を選ぶ操作は設けない。
- 暗い配色では、運動の印（緑 `#2D7F63`）と塗りが近い（コントラスト比 2.6 前後）。そこで印に淡い縁（`--mark-ring`、`#E4E8F7`、1.5px）を付け、縁と塗りの差で形を見分けられるようにした。塗りは、便マーク（硬い）が 3 以上になる明るさに抑えた。どちらも `palette.test.ts` で確かめる（2026-11-26 実装時に解消）。

### 数字

| 用途 | 書体・サイズ |
|---|---|
| 主役の数字（今月食べた、連続） | DM Sans 600、30px |
| 単位と説明（日、今月食べた） | 和文 900、12〜13px |
| 添える情報（先月26日まで 12日 など） | 和文 500、11px。数字だけ DM Sans 600、12px、墨 |

### 動き

| 場面 | 動き |
|---|---|
| 記録・取り消し | マスの印が判子を押すように現れる（初版のカレンダーの印と同じ）。数字はすぐ切り替える |
| 運動のボタン | 押すと緑に塗られ、「＋」が「✓」に変わる |
| 知らせ | 下から浮かび上がる（初版のトーストと同じ） |

### 文言

| 場面 | 文言 |
|---|---|
| 記録したとき | 〇〇を記録しました（取り消す） |
| 取り消したとき | 〇〇を取り消しました（元に戻す） |
| 引き継いだとき | これまでの記録から N日分を引き継ぎました |
| 食べたものを選ぶシート | 何を食べた？ |
| ログイン画面の一言 | 日々を、押していく。（初版のまま） |
