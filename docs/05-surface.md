## 1. コンセプト：日めくり × 判子

**日々を、押していく。**

日めくりカレンダーの紙片に、食べたものの印（判子）を押していく帳面として描く。

| 要素 | 表現 | 由来 |
|---|---|---|
| 地 | 淡い空色の単色 | 目に優しい舞台。紙と印を引き立てる |
| 1日 | 白い紙片（角丸の札） | 日めくりの1枚 |
| 日付 | 太いディドニ体の数字 | 日めくりカレンダーの数字 |
| 食べたもの | 1文字の印。グループごとのインク色 | 判子。少しずつ傾けて、手で押した表情を出す |
| 記録の操作 | チップを押すと、その場でインク色に変わる | 「選ぶ」ではなく「押す」 |

### 方針

| 方針 | 内容 |
|---|---|
| 大胆に、ただし1か所で | 強い表現は「太い数字・色の印」に集める。地は淡く保つ。それ以外（文字、余白、線）は静かにする |
| 評価しない | 色や形で、食事や便に良し悪しの印象を与えない。赤は警告ではなく、印のインク色の1つとして扱う |
| 色に頼りきらない | カテゴリは文字、便は形、選択状態はチェックと太字でも区別する |
| 褒めない | 保存時の祝う演出、継続を褒める演出は入れない。動きは「押した」「移った」を伝えるためだけに使う |

テーマは1種類のみとする（Q30）。

## 3. 便マーク

単色（墨）の SVG とし、輪郭の形で4種を区別する。色は形状によって変えない（Q33）。

| 形状 | 形 | 図の説明 |
|---|---|---|
| 硬い | 小さな粒が3つ | 塗りの円3つを三角形に配置 |
| 普通 | 楕円 | 横長の塗りの楕円 |
| 柔らかい | 雲形 | 平らな底に、丸いふくらみが3つ並ぶ塗りの形 |
| 下痢 | しずく | 塗りのしずく形 |

- 排泄物を写実的に描かない。良し悪しを示す表情や記号を付けない。
- 月表示の前後の月の日では、薄く（55%）描く。
- 量と排便感はマークで表さず、日別詳細の文字でのみ示す。
- 将来ブリストルスケールに拡張するときは、マークを見直す。

## 4. タイポグラフィ

Web フォントを2書体使う（Google Fonts）。初回の取得後は Service Worker が端末に保持する。

| 役割 | 書体 | 使う場所 |
|---|---|---|
| 数字 | Bodoni Moda 700–900 | 日付、期間、時刻。日めくりの太い数字 |
| 和文 | Zen Kaku Gothic Antique 500／900 | それ以外のすべて。印の1文字は 900 |

読み込めない場合は、数字は端末の Bodoni 72／Didot、和文はヒラギノ角ゴにフォールバックする。

| 用途 | サイズ | 太さ |
|---|---|---|
| 週の日付 | 26px（今日は丸の中に 20px） | 800 |
| 期間の見出し（11/9–15） | 23px | 800 |
| ヘッダーの日付の数字 | 24px | 800 |
| 月表示の日付 | 16px | 800 |
| 時刻（日別詳細） | 19px | 700 |
| ボタン（保存、食事、便） | 17px | 900 |
| 本文、チップ、リスト | 15px | 500（選択中のチップは 900） |
| 印の1文字 | 14px | 900 |
| 見出しラベル（主食、形状など） | 11px、字間 .08em | 900 |

- ヘッダーの日付は「**11**月**10**日 ㊋」のように、数字を大きく、曜日を丸囲みで組む。
- 月の見出しは「**2026**年**11**月」の単位（年・月）を小さくする。

## 5. 形と余白

| 要素 | 値 |
|---|---|
| 入力シートの上の角丸 | 22px |
| 紙片（週の1日） | 角丸 14px、紙片の間隔 4px |
| 月のマス | 角丸 10px、間隔 3px |
| 印 | 24px 角、角丸 6px。−2°〜2.5° の範囲で少しずつ傾ける |
| チップ | 角丸 10px、高さ 40px |
| ボタン | 角丸 12px（カレンダーの記録ボタンは 14px、高さ 48px） |
| 影 | 今日の紙片、記録ボタン、トーストのみ（空色の地に落とす、淡い青灰の影） |

内側の画面（日別詳細、記録、カテゴリ）は、空色のヘッダーの下に白いシートを重ねた構成とする。線で区切り、カードは重ねない。

## 6. 部品の状態

| 部品 | 状態 | 見た目 |
|---|---|---|
| チップ | 未選択 | 紙（淡）、墨の文字 |
| | 選択 | グループのインク色で塗る。太字、左にチェック |
| 便の形状チップ | 選択 | 墨で塗り、マークと文字を白にする |
| セグメント | 選択中 | 墨で塗り、白文字 |
| 保存ボタン | 有効／無効 | 藍に白文字／罫線色に補助文字 |
| 週の紙片 | 過去 | 紙（淡） |
| | 今日 | 紙（白）＋影。日付を藍の丸で囲み、曜日も藍（濃）にする |
| | 未来 | 塗らず、墨の薄い輪郭のみ。文字は墨の 50% |
| 月のマス | 今日 | 紙（白）＋影。日付を藍の丸で囲む |
| | 前後の月 | 白の 32% で塗り、文字は補助文字色 |
| 押下中 | 共通 | わずかに縮める（.96〜.985） |

### 動き

| 場面 | 動き | 時間 |
|---|---|---|
| 記録シートを開く／閉じる | 下からせり上がる／下へ降りる。奥の画面はわずかに退く | 340ms |
| 階層を進む／戻る | 右から入る／右へ出る | 340ms |
| チップを押す | 少し縮んで傾き、戻る（判子を押す感触） | 280ms |
| カレンダーの印 | 大きめの状態から、順に押されるように現れる | 260ms、16ms ずつ遅延 |
| トースト | 下から浮かび上がる | 300ms |

- 画面遷移は View Transitions API で行う。対応していないブラウザでは、動きなしで切り替わる。
- 端末のスワイプ操作で戻った場合は、OS 側の動きと重ならないよう、アプリ側の動きを付けない。
- 端末の「視差効果を減らす」設定が有効なときは、すべての動きを止める。

## 7. 文言

断定せず、短く、事実だけを伝える。

| 場面 | 文言 |
|---|---|
| 保存の成功 | 記録しました |
| 削除の成功 | 削除しました |
| 削除の確認 | この記録を削除しますか？ |
| 保存の失敗 | 保存できませんでした。もう一度お試しください |
| オフライン | 通信できないため保存できません |
| 読み込みの失敗 | 読み込めませんでした |
| 記録がないとき | 未記録 |
| 名称変更の注意 | 名称の変更は過去の記録にも反映されます |
| ログイン画面の一言 | 日々を、押していく。 |

## 8. アプリの外観

ホーム画面に常に表示されるため、記録の内容を連想させない外観にする（Q31）。

| 項目 | 内容 |
|---|---|
| アプリ名 | ひびログ |
| アイコン | 淡い空色の地の中央に、にっこり顔の日めくり1枚（ピンクの帯、白い頬紅、2つの目と口）と、右下に重なる小さな黄色の判子。食事や便のモチーフは使わない。[scripts/gen-icons.mjs](../scripts/gen-icons.mjs) で生成する |
| ステータスバー | 半透明（`black-translucent`）。ページをステータスバーの下まで延ばし、空色の地を上端までつなげる。iOS 26.1 以降はこの指定で上端に端末側のぼかしがかかり、ページから消せない（2026-11-11 実機で確認。指定を外しても消えなかった）。そこで画面の上端を「安全領域の高さ＋12px」空け、ぼけるのが無地の余白だけになるようにする |

## 9. 判断事項

| # | 問い | 決定 | 理由 |
|---|---|---|---|
| Q30 | ダークテーマを用意するか | 用意しない | 地が淡い色でも、墨の文字は暗い環境で眩しすぎない。配色の検証も1通りで済む |
| Q31 | アプリ名とアイコン | 「ひびログ」、顔つきの日めくりのアイコン（Q42で変更） | ホーム画面で他人に見られても、記録の内容がわからない |
| Q32 | グループの配色 | 2章の5色。「その他」は墨 | 揚げ物の判別を G2 の基準に合わせて強める |
| Q33 | 便マークの表現 | 3章の4種。単色で、輪郭の形で区別する | 評価の印象や不快感を避け、小さくても区別しやすい |
| Q39 | 見た目の方向（2026-11-10 追加） | 「日めくり × 判子」。空色の地（Q41で変更）、ディドニ体の数字、色インクの印、画面遷移の動き | 初版は無難で印象に残らなかった。記録するたびに触りたくなる質感を、継続（G1）の後押しにする |
| Q40 | Web フォントを使うか（2026-11-10 変更） | 使う（2書体）。初版の「読み込まない」を変更 | 数字と印の表情がコンセプトの中心であるため。初回のみ読み込みが増え、以後は端末に保持する |
| Q41 | 地の色（2026-11-11 追加） | コバルト `#2A3FD4` → 淡い空色 `#CFDDF6`。ヘッダーの文字は白 → 墨。印の色も彩度を少し落とす | 実機で見たところ、コバルトが目に強かった。優しい色合いにしつつ、日めくり×判子の構図は保つ |
| Q42 | アイコンの絵柄（2026-11-11 追加） | 横線3本 → にっこり顔の日めくり＋小さな判子 | 実機で見たところ、無機質だった。可愛げを出しても、食事や便は連想させない |

初版からの主な変更は、配色（クリーム＋青緑 → 淡い空色＋白＋藍）、書体（システム書体 → Web フォント）、動き（最小限 → 遷移と押印）、「赤は削除のみ」の原則（→ 朱は印のインク色としても使う）の4点である。
