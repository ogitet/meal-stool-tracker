## 1. 見た目の方針

| 方針 | 内容 | 根拠 |
|---|---|---|
| 静かで私的 | 医療アプリや健康管理アプリらしさを避け、落ち着いた日用品の印象にする | 個人の記録基盤 |
| 評価しない | 色や形で、食事や便に良し悪しの印象を与えない | 因果関係を断定しない |
| 情報の色だけを目立たせる | 画面の土台は無彩色に近づけ、カテゴリ印の色で週の傾向を読めるようにする | G2 |
| 色に頼りきらない | カテゴリは文字、便は形、選択状態はチェックでも区別する | Skeleton の方針 |

## 2. 配色

MVP はライトテーマのみとする。→Q30

### 基本色

| 役割 | 色 | 用途 |
|---|---|---|
| 背景 | `#FAF8F5` | 画面全体 |
| 面 | `#FFFFFF` | チップ、リスト行 |
| 本文 | `#2B2A28` | 通常の文字 |
| 補助文字 | `#69645C` | 見出し、未記録、時刻 |
| 枠線 | `#C9C3B8` | チップの輪郭 |
| 区切り線、無効の面 | `#E4E0D9` | 行の区切り、無効のボタン |
| 主色 | `#1F6F6B` | 保存、選択状態、今日の印 |
| 今日の背景 | `#E3F1EF` | 週カレンダーの今日の行 |
| 削除 | `#B3362B` | 「削除」の文字、確認シートの削除ボタン |
| トースト | `#2B2A28` | 背景。文字は白 |

主色は、体調の良し悪しを連想させにくい青緑とする。赤は削除のみに使う。

### カテゴリ印のグループ色

→Q32

| グループ | 背景 | 文字 | コントラスト比 |
|---|---|---|---|
| 主食 | `#F6E3B4` | `#5F4200` | 7.31 |
| 肉・魚・卵 | `#F8D3CF` | `#7A1D18` | 7.54 |
| 野菜・果物 | `#CFE8CC` | `#1B5527` | 6.76 |
| その他 | `#454B57` | `#FFFFFF` | 8.76 |
| お菓子 | `#E7D8F6` | `#55278A` | 7.61 |

- 食材を表すグループは淡い色で揃える。
- 「その他」は揚げ物、辛いもの、お酒など、便との関係で特に見たいものの集まりであるため、濃色にする。これにより「揚」が週の中で見つけやすくなる。
- 追加したカテゴリは所属グループの色を使う。利用者が色を選ぶ操作は設けない。

### その他のコントラスト比

| 組み合わせ | 比 |
|---|---|
| 本文／背景 | 13.53 |
| 本文／今日の背景 | 12.36 |
| 補助文字／背景 | 5.54 |
| 補助文字／今日の背景 | 5.06 |
| 白文字／主色 | 5.92 |
| 主色／今日の背景 | 5.11 |
| 削除／背景 | 5.69 |
| 便マーク（`#4F4B45`）／背景 | 8.17 |
| 便マーク／今日の背景 | 7.46 |

文字と便マークは、すべて WCAG AA の基準（4.5以上）を満たす。枠線は装飾的な補助であり、チップの識別は文字で行う。

## 3. 便マーク

単色（`#4F4B45`）の SVG とし、塗りと形で4種を区別する。色は形状によって変えない。→Q33

| 形状 | 形 | 図の説明 |
|---|---|---|
| 硬い | 小さな粒が3つ | 塗りの円3つを三角形に配置 |
| 普通 | 塗りの楕円 | 横長の楕円 |
| 柔らかい | 雲形 | 平らな底に、丸いふくらみが3つ並ぶ塗りの形（2026-11-10、輪郭のみの楕円から変更） |
| 下痢 | しずく | 塗りのしずく形 |

- 排泄物を写実的に描かない。
- 良し悪しを示す表情や記号を付けない。
- 14px で判別できることを試作で確認する。
- 量と排便感はマークで表さず、S-03 の文字でのみ示す。
- 将来ブリストルスケールに拡張するときは、マークを見直す。

## 4. タイポグラフィ

Webフォントは読み込まず、端末標準の書体を使う（表示速度と無料枠の節約のため）。

```
-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", sans-serif
```

| 用途 | サイズ | 太さ |
|---|---|---|
| 画面名、対象の日 | 16px | 600 |
| 記録バー、保存ボタン | 17px | 600 |
| 本文、リスト行、入力欄 | 16px | 400 |
| チップ | 15px | 500 |
| 食事枠のセグメント | 13px | 600 |
| 週カレンダーの日 | 17px | 600 |
| 週カレンダーの曜日 | 12px | 400 |
| カテゴリ印 | 14px | 700 |
| グループ見出し | 12px | 600 |
| 未記録、補足 | 13px | 400 |

- 時刻と日付の数字は等幅の数字を使い、行の位置を揃える。
- チップ内の名称が長い場合は 12px に下げ、2行まで折り返す（名称は10文字以内）。
- 土曜と日曜の文字色は変えない。

## 5. 形と余白

| 要素 | 値 |
|---|---|
| 余白の単位 | 4px の倍数 |
| 画面左右の余白 | 12px |
| カテゴリ印の角丸 | 5px |
| チップの角丸 | 8px |
| ボタンの角丸 | 10px |
| 確認シートの上部の角丸 | 16px |
| 影 | 確認シートとトーストのみ |

線と余白で区切り、カードを重ねた見た目にはしない。

## 6. 部品の状態

| 部品 | 状態 | 見た目 |
|---|---|---|
| チップ | 未選択 | 面の色、枠線、本文の文字 |
| | 選択 | 主色の塗り、白文字、左にチェック |
| セグメント | 選択中 | 主色の塗り、白文字 |
| 保存ボタン | 有効 | 主色の塗り、白文字 |
| | 無効 | 無効の面、補助文字 |
| | 保存中 | 主色のまま、文字を処理中の表示に替える |
| 「前回をコピー」 | 通常 | 面の色、主色の枠線と文字 |
| 記録バーの食事／便 | 通常 | 主色の塗り、白文字。2つを同じ強さで示す |
| 週カレンダーの行 | 今日 | 今日の背景、左端に主色の太線、日付を主色に |
| | 未来 | 全体を不透明度 40% にする |
| 月カレンダーのセル | 今日 | 日付を主色の円で囲む |
| | 未来 | 全体を不透明度 40% にする |
| グループ見出し | 通常 | 左にグループ色の小さな四角を添え、印の色との対応を覚えられるようにする |
| 押下中 | 共通 | 少し暗くする |

### 動き

- 画面遷移と確認シートは 150ms 程度の控えめな動きにする。
- 端末の「視差効果を減らす」設定が有効なときは動きを止める。
- 保存時の演出や、継続を褒める演出は入れない。

## 7. 文言

断定せず、短く、事実だけを伝える。

| 場面 | 文言 |
|---|---|
| 保存の成功 | 記録しました |
| 削除の成功 | 削除しました |
| 削除の確認 | この記録を削除しますか？ |
| 保存の失敗 | 保存できませんでした。もう一度お試しください |
| オフライン | 通信できないため保存できません |
| 読み込みの失敗 | 読み込めませんでした |
| 記録がないとき | 未記録 |
| 名称変更の注意 | 名称の変更は過去の記録にも反映されます |

## 8. アプリの外観

ホーム画面に常に表示されるため、記録の内容を連想させない外観にする。→Q31

| 項目 | 内容 |
|---|---|
| アプリ名 | ひびログ |
| アイコン | 主色の背景に、週カレンダーの行を抽象化した白い横線。文字や便のモチーフは使わない |
| 起動時の背景とテーマ色 | 背景 `#FAF8F5` |

カテゴリ管理の入口は、スライダー形のアイコンに「カテゴリ管理」の読み上げラベルを付ける。

## 9. 判断事項

すべて 2026-11-10 に確定済み。

| # | 問い | 決定 | 理由 |
|---|---|---|---|
| Q30 | ダークテーマを用意するか | MVP では用意しない | カテゴリ印の配色検証が倍になる。夜間に眩しければ追加する |
| Q31 | アプリ名とアイコン | 「ひびログ」、抽象的なカレンダーのアイコン | ホーム画面や通知領域で他人に見られても、記録の内容がわからない |
| Q32 | グループの配色 | 2章の5色。「その他」のみ濃色（2026-11-10、カテゴリの見直し Q38 に合わせて変更） | 揚げ物の判別を G2 の基準に合わせて強める |
| Q33 | 便マークの表現 | 3章の4種。単色で、塗りの有無ではなく輪郭の形で区別する | 評価の印象や不快感を避け、小さくても区別しやすい |
